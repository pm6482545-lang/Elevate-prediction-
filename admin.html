Naming rule (rename files before uploading)

Use this pattern with underscores: Subject_Grade_Term Stage_Item

  • Mathematics_Grade 6_Term 1 Opener_Exam.pdf
  • English_Grade 8_Term 2 Mid_Exam.pdf
  • Science and Technology_Grade 5_Term 3 End_Exam.pdf
  • Kiswahili_Grade 7_Term 1_Scheme of Work.pdf
  • Mathematics_Grade 9_Lesson Plan.pdf
  • Mathematics_Grade 6_Term 1 Opener_Marking Scheme.pdf

Stage is Opener, Mid or End. Term and stage are optional (leave them out for notes, lesson plans, etc.). The file name becomes the product name on the website, so spell it the way you want customers to see it. No descriptions needed.

Batch settings

Covers are made automatically from page 1 of each PDF. Word or Excel files get a branded cover with the file name.
